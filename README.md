# Introduction to Linux - Source Files

These are some of the source files used for the **Introduction to Linux** workshop.

## Build

How to build PDF documents:
* Open the repo in VSCode/VSCodium.
* Install the [Markdown PDF](https://open-vsx.org/vscode/item?itemName=yzane.markdown-pdf) extension.
* Apply the settings at the top to `settings.json`. The workspace version of it is recommended.
* Press Ctrl+Shift+P and select "Markdown PDF: Export (pdf)".
