# Change Screen Resolution in Linux Mint

1. Right-click on the desktop and press "Display Settings".
2. Go to the Resolution dropdown menu and choose a smaller screen resolution.<br>
   Recommendations:
   * 1440x900 or 1366x768 for 1080p (1920x1080) displays.
   * 1360x768 for 768p (1366x768) displays.<br>
     Consider running the VM in fullscreen mode, which can be toggled with HostKey+F.
3. Press "Apply".
4. Press "Keep changes" if satisfied.
5. Close the display settings to hide the screen number indicators.
